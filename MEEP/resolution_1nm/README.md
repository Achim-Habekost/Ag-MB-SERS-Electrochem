# MEEP simulation: 1.0 nm grid

This directory contains the symmetric 2 × 2 Ag nanoparticle simulation at a grid spacing of 1.0 nm.

Simulation parameters:
- Excitation wavelength: 785 nm
- Ag particle diameter: 50 nm
- Interparticle gap: 2 nm
- Grid spacing: 1.0 nm
- Surrounding medium: refractive index 1.33

The calculated electric-field enhancement factor is 8.621 at both the upper and lower horizontal gap-center monitor points.

The corresponding 0.5 nm calculation gives 8.581 at both points, a relative difference of approximately 0.46%.

This comparison concerns the selected gap-center monitor points only; convergence of the complete spatial field map has not been established.

The simulation script, numerical results, reference-field data, and field visualization are archived in this directory.
