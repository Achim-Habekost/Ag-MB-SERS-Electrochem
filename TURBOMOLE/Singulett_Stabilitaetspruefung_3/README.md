# Singlet SCF stability analysis

This directory archives the TURBOMOLE files for the singlet SCF stability analysis of the Ag40–MB+ model.

# SCF stability analysis

The TURBOMOLE stability calculations are documented in escf_stabilitaet.log, escf_stabilitaet_2.log, and escf_singulett.log.

The output escf_stabilitaet_2.log reports a positive SCF energy-Hessian eigenvalue of approximately 3.927 × 10⁻⁴. The dominant contribution (91.5%) corresponds to the occupied-to-virtual orbital pair 455 → 456. The calculation terminated normally.

This positive eigenvalue indicates positive curvature along the reported stability mode. It does not, by itself, establish stability against all possible electronic perturbations or prove that the singlet is energetically preferred over the triplet.

The mos.zip archive contains the molecular orbital file and must be extracted before reuse.
