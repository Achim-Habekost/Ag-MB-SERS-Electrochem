# Raman calculation: Ag40–MB+

This directory archives the TURBOMOLE input and output files for the Raman calculation of the Ag40–methylene blue (MB+) model used in the SERS study.

The archive includes the molecular coordinates, computational settings, basis-set definitions, SCF results, vibrational data, Raman calculation files, and supplementary spectral analyses.

Large orbital and Raman-related files are provided as ZIP archives and must be extracted before reuse.

The original calculation outputs are retained to document the computational results and their limitations. Completion of a calculation alone does not establish that the optimized structure is a local minimum or that the electronic state is stable.
