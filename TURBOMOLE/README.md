# TURBOMOLE calculations

This directory documents the quantum-chemical calculations for the Ag40–MB+ model used in the SERS study.

The calculations include:
- Geometry optimization and vibrational/Raman calculations.
- Singlet and triplet electronic-state calculations at identical nuclear geometry.
- SCF stability analyses of the singlet reference state.

The calculations use the PBE functional with D3(BJ) dispersion correction and the def-SV(P) basis set, including an effective core potential for Ag.

Input files, relevant output files, optimized coordinates, and calculation details will be provided here.

The electronic-state comparison and stability analyses refer to the complete Ag40–MB+ complex, not to isolated Ag or methylene blue.
